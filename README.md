# AI Image Generator

An AI-powered image generation web application built using Java, Spring Boot, Thymeleaf, HTML and CSS.

## Features

- Generate images from text prompts
- Select image size
- Select image style
- Simple and user-friendly web interface
- Spring Boot backend
- Thymeleaf frontend
- API integration for image generation
- Secure API key configuration using environment variables

## Technologies Used

- Java
- Spring Boot
- Maven
- Thymeleaf
- HTML
- CSS
- REST API
- Git & GitHub
